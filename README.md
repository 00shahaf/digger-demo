# Digger Demo

Downloads of the Demo edition of [Digger](https://dumpsterfirestudio-art.com/digger/), excavation recording software for field archaeologists. This repository holds only the demo's download files, not source code.

**[Go to the downloads](https://github.com/00shahaf/digger-demo/releases/latest)**: under **Assets**, click the `.exe` file for Windows or the `.AppImage` file for Linux. You don't need a GitHub account.

The Demo edition is for a first look: one project (Tel Demo), one area, 16 loci or contexts, 21 baskets or finds and 10 photos, with marked PDFs. It isn't for commercial use or actual excavations. The Context recording method is experimental.
