# Digger Student

Downloads of the Student edition of [Digger](https://diggersoftware.site/), excavation recording software for field archaeologists: loci and baskets, contexts, US/USM, plans, sections, heights, finds, photos and the Harris matrix, with report PDFs. Interface in English, Hebrew, French, German, Italian and Spanish. This repository holds only the download files, not source code.

**[Go to the downloads](https://github.com/00shahaf/digger-demo/releases/latest)**: under **Assets**, click the `.exe` file for Windows or the `.AppImage` file for Linux. You don't need a GitHub account.

The Student edition is for learning and teaching: one area, up to 50 loci or units and 100 baskets or finds, unlimited photos, and watermarked report PDFs. On first start it asks you to accept its terms: learning only, no commercial use and nothing published. The full edition is coming soon.

The illustrated tutorial and more information are on the website: **https://diggersoftware.site/**
